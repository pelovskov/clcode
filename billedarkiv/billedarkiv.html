Sådan bruger du det lokale billedarkiv

Denne HTML-app er skabt til at køre 100% lokalt på din egen computer uden problemer med CORS eller krav om et webhotel.

1. Indlæs dine egne billeder

Klik på "Forbind mappe" øverst og vælg arkivmappen (den mappe, hvor denne HTML-fil og dine billeder ligger – gerne på et USB-stik). Chrome spørger, om siden må redigere filer i mappen: svar Ja / Tillad. Undermapper bliver automatisk til albums.

Næste gang du åbner filen, står der en grøn knap "Genforbind …" – klik på den og bekræft, så er du i gang igen.

Virker i Google Chrome, Microsoft Edge og Chromium (Linux). Ikke i Safari og Firefox.

2. Sortering og Albums (Træk & Slip)

  • Ændr rækkefølge: Tag fat i et billede med musen og træk det hen på den plads, det skal have.
  • Flyt til andet album: Træk et billede fra galleriet direkte over på et album-navn i menuen til venstre!
  • Rediger tekst og årstal: Klik på et billede for at åbne det i stort format og tilføje lokalhistoriske beskrivelser.

3. Sådan gemmes dit arbejde

Alt gemmes automatisk i filen arkiv-data.json inde i arkivmappen, hver gang du retter en tekst, flytter et billede eller opretter et album. Der er ingen gem-knap at huske.

Fordi tekster og sortering ligger i mappen sammen med billederne, kan du flytte hele mappen eller USB-stikket til en anden computer og fortsætte dér.

Tip: Tag jævnligt en kopi af arkiv-data.json – den indeholder alt dit arbejde.

Denne opdaterede api.php finder automatisk alle billeder og undermapper – uanset om dine billeder ligger i en mappe kaldet billeder, Billeder eller i andre undermapper ved siden af HTML-filen!

Sådan gør du på dit webhotel:

  1. Opdater din api.php på webhotellet med den nye kode herunder (den finder selv alle billedmapper).
  2. Opdater også din index.html på webhotellet med koden fra dette dokument.
Opdateret indhold til api.php (Finder automatisk alle billedmapper): 
<?php
header('Content-Type: application/json; charset=utf-8');
$dataFile = 'arkiv-data.json';

// 1. Håndter GEM (Når du trækker billeder eller retter tekst)
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $input = file_get_contents('php://input');
    if (json_decode($input) !== null) {
        file_put_contents($dataFile, $input);
        echo json_encode(['status' => 'ok']);
    } else {
        http_response_code(400);
        echo json_encode(['error' => 'Ugyldig JSON']);
    }
    exit;
}

// 2. Håndter HENT (Scanner automatisk nuværende mappe og alle undermapper for billeder)
$saved = file_exists($dataFile) ? json_decode(file_get_contents($dataFile), true) : ['albums' => [], 'photos' => []];
$files = [];
$baseDir = __DIR__;

$iterator = new RecursiveIteratorIterator(
    new RecursiveDirectoryIterator($baseDir, RecursiveDirectoryIterator::SKIP_DOTS)
);

foreach ($iterator as $file) {
    if ($file->isFile() && preg_match('/\.(jpg|jpeg|png|gif|webp|bmp)$/i', $file->getFilename())) {
        // Find relativ sti fra mappen hvor api.php ligger
        $relPath = substr($file->getPathname(), strlen($baseDir) + 1);
        $relPath = str_replace('\\', '/', $relPath);
        
        // Find mappenavn (til automatisk album)
        $dirName = dirname($relPath);
        $folder = ($dirName === '.' || strtolower($dirName) === 'billeder') ? 'all' : basename($dirName);

        // URL-encode hver del af stien så mellemrum og æøå virker i browseren
        $urlParts = array_map('rawurlencode', explode('/', $relPath));
        $safeUrl = implode('/', $urlParts);

        $files[] = [
            'id' => $relPath,
            'filename' => $file->getFilename(),
            'folder' => $folder,
            'url' => $safeUrl
        ];
    }
}

echo json_encode(['saved' => $saved, 'scannedFiles' => $files], JSON_UNESCAPED_UNICODE);
?>
